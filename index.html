hatex demos

Each page fetches one .tex file and typesets it in your browser with hatex.

  • Denoising Diffusion Models, Derived

    A two-column paper (\documentclass[twocolumn]): propositions and proofs, numbered equations, TikZ and pgfplots figures, algorithms, code, references.

  • 洛陽伽藍記序

    A classical Chinese text set like an old book (\begin{guji}): vertical columns from right to left in traditional characters, ruled like a manuscript scroll, with two-line interlinear notes (\jiazhu) and 句讀 marks in place of punctuation.

  • hatex slides

    A beamer deck (\documentclass{beamer}): title page, outline, blocks, columns, maths, code and a full-screen presenter.

Sources: github.com/mejistus/hatex-demo (these pages) and github.com/mejistus/hatex (hatex itself), MIT License.
